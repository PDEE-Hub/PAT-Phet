รูปแบบการกรอก
1.1 ใช้ชุดเบิกจ่ายจริง/แผนรายเดือนร่วมกันคำนวณทั้งสองตัวชี้วัดย่อย
1.2 ค่าใช้จ่ายฝึกอบรมสะสม / กรอบทั้งปี × 100 (กรอบเริ่มต้น 26 ล้านบาทตาม Excel)
1.3 ค่า Factor และสรุปผล พร้อมยืนยันคะแนนตามเกณฑ์
1.4 ปริมาณปล่อยก๊าซจริงสะสม พร้อมยืนยันคะแนนระหว่างปีตามวิธีประเมินเดิม
2.1 รายได้ − ค่าใช้จ่าย + ภาษีที่ดินและสิ่งปลูกสร้างบวกกลับ แยก กทท./ทกท./ทลฉ.
2.2 รายได้รายเดือน Q3 บวกยอดสะสม Q2
2.3 ปริมาณ ICD+ทกท. และลาน C เฉพาะ Q3 บวกยอดสะสม Q2
2.4 ผลรายเดือน Q3 บวกยอดสะสม Q2 ตาม R2 ที่ผ่าน
2.5 กรอกผล 3 ด้าน พร้อมข้อความ หลักฐาน และคะแนนที่ยืนยันตามเกณฑ์
2.6 รายได้จากสินทรัพย์สะสม แยกสำนักงานใหญ่/ทกท./ทลฉ./ทรน./ทชส.
2.7 คงการกรอกความคืบหน้ารายเดือนและผู้ดูแลยืนยัน ใช้เดือนรายงานล่าสุด ไม่ใช้ลำดับที่คลิกยืนยัน
2.8 ข้อความผลดำเนินงาน หลักฐาน และคะแนนที่ยืนยันของแต่ละท่าเทียบเรือ

หน้ารายละเอียด
เปิดได้ครบ 28 รายการหลักและย่อย เปลี่ยนดู Q1–Q4 ได้
แสดงผล คะแนน เกณฑ์ เป้าหมาย คาดการณ์ ผู้รับผิดชอบ ข้อมูลประกอบและแผนงานที่มีในต้นทาง
ตัวชี้วัดหลักรวมคะแนนถ่วงน้ำหนักจากตัวชี้วัดย่อย และบอกความครบถ้วนของข้อมูล
ค่ารายงานที่เป็นปริมาณ/เปอร์เซ็นต์แยกจากคะแนนที่ผู้ประเมินยืนยัน
ข้อมูลที่ไม่มีต้นทางยังเว้นว่าง ไม่สร้างผลหรือเอกสารประกอบขึ้นเอง

CSS Consolidation
Home ใช้ home.css ชุดเดียว รวมกฎเริ่มต้นและ responsive ที่ยังจำเป็น
ลบประกาศ CSS ที่ถูกกฎใหม่แทนที่แล้ว 303 รายการ
shared.css เก็บสไตล์ส่วนกลาง/หน้าต่างๆ และ reporting.css ใช้โทนของ R2 กับหน้ากรอก/ภาพรวม/แจ้งเตือน
ตรวจลำดับประกาศ CSS สำหรับ selector เดิมที่ 42 ขนาดหน้าจอ/ความสูงก่อนและหลังรวม
ยังไม่ได้ทดสอบภาพหน้าจอผ่านเบราว์เซอร์
